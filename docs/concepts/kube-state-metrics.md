# kube-state-metrics integration

> **Moved:** The kube-state-metrics CustomResourceState configuration for ironcore.dev
> CRDs has moved to `metal-telemetry-operator`. Enable it there via
> `kubeStateMetrics.enabled: true` or `kubeStateMetrics.sidecarDiscovery.enabled: true`.
>
> See [`metal-telemetry-operator/docs/concepts/kube-state-metrics.md`](../../../metal-telemetry-operator/docs/concepts/kube-state-metrics.md)
> for full documentation and wiring examples.
